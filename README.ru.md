# Миллион идентификаторов

[English](README.md) | **Русский**

Два списка для реестра из 1 000 000 ID: слева всё, что не выбрано, справа выбранное в заданном порядке.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm test
npm run dev
```

Интерфейс: http://localhost:5173

Продакшен, одним процессом:

```bash
npm run build
npm start
```

Приложение: http://localhost:3000

Состояние выбора общее для всех открытых вкладок и живёт в памяти процесса. После перезапуска сервера выбор сбрасывается. Несколько процессов между собой память не разделяют.

Фильтры хранятся только в состоянии страницы и пропадают при обновлении.

## Как устроены списки

Базовые ID `1…1000000` не записываются в массив. Страница из 20 доступных элементов вычисляется: дополнительные ID лежат в отсортированных массивах, а дырки внутри базового диапазона находятся двоичным поиском.

Порция всегда 20 элементов. Следующая подгружается, когда низ списка подходит к видимой области.

Фильтр — вхождение введённой строки в десятичную запись ID.

Drag & Drop на правом списке переставляет загруженные строки. Элементы, которые фильтр скрыл или которые ещё не подгрузились, остаются на своих позициях.

Новый ID задаётся строкой, поэтому подходят и числа длиннее `2^53`. Повтор уже существующего ID отклоняется сразу.

## Очередь

- Чтение списков и изменение выбора/порядка копятся и выполняются одним пакетом раз в секунду. В одном пакете сначала применяются записи, затем чтения, поэтому чтение видит уже применённые изменения.
- Одинаковые чтения внутри окна сливаются в один запрос. Повторный выбор или возврат того же ID, пока операция ждёт, присоединяется к ней. Противоположная операция встаёт следом и не затирается.
- Добавление выполняется пакетом раз в 10 секунд. Пока ID зарезервирован, параллельные добавления того же значения получают один результат и создают одну запись.

Служебный `GET /api/meta` отвечает сразу: это телеметрия очереди, а не чтение реестра.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/items?side=available\|selected&filter=&offset=` | Порция из 20 элементов |
| POST | `/api/items` `{ "id": "1000001" }` | Добавить ID |
| POST | `/api/selection` `{ "id": "5" }` | Выбрать |
| POST | `/api/selection/remove` `{ "id": "5" }` | Вернуть |
| POST | `/api/selection/reorder` `{ "ids": ["3","1"] }` | Переставить загруженное подмножество |
| GET | `/api/health` | Проверка процесса |
| GET | `/api/meta` | Счётчики и ближайшие пакеты |

Интервалы можно поменять переменными `DATA_BATCH_MS` и `ADD_BATCH_MS`.
